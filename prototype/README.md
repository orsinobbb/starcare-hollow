# 《星癒小鎮》小鎮核心原型

這個版本把可愛角色、療癒所調度與主動技能接回可累積的小鎮主系統。藥園採收、居民委託、診療班次、星願日程、建築升級、地區修復與「星願手札」永久收藏共用同一份本機存檔；不需要安裝第三方套件。

## 啟動

在本資料夾執行：

```powershell
npm start
```

然後開啟 <http://127.0.0.1:4173>。

模擬 GitHub Pages 的儲存庫子路徑：

```powershell
npm run start:pages
```

開啟 <http://127.0.0.1:4173/starcare-hollow/>。

## 操作

- 小鎮：採收藥園、交付居民委託、進入療癒所並用資源升級建築。
- 收藏：行動會解鎖八種不會被消耗的手札紀念物；舊版進度會自動保留與補發。
- 星願：完成三項今日目標後領取修復禮，再由玩家決定何時進入下一日。
- 療癒所：先點選一位居民，再依她目前的需求安排觀察、調製、療護或安撫工作站。
- 優先順序：耐心會隨時間下降，橘色與紅色提示代表更急迫的工作。
- 搭檔技能：每四次正確照護充滿能量，可自行選擇「月芽盛放」、「星時停駐」或「安心抱抱」。
- 鍵盤：Tab 移動焦點、Enter／空白鍵操作按鈕、Escape 暫停或關閉說明。
- 手機：所有核心操作都是點按，頁面可正常上下滑動。

小鎮進度會自動保存在目前瀏覽器的 `localStorage`。重新整理或下次開啟同一網址時會繼續使用原進度。

## 驗證

```powershell
npm run check
```

網址參數可縮短測試，例如 `?view=clinic&duration=30&goal=2&seed=test&debug=1`。正式預設仍是 180 秒、目標 5 人。

公開版由 `main` 分支自動發布至 <https://orsinobbb.github.io/starcare-hollow/>。版本升級、存檔相容與回復方式見 [GitHub 發布與長期升級規格](../docs/09_GITHUB_RELEASE_UPGRADE.md)。
