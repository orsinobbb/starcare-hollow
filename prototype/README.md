# 《星癒小鎮》小鎮核心原型

這個版本把可愛角色、三種配對小遊戲與主動技能接回可累積的小鎮主系統。藥園採收的月芽葉可在遠征中調製暖茶、回復羅盤專注；居民委託、小遊戲、星願日程、建築升級、地區修復與「星願手札」永久收藏共用同一份本機存檔；不需要安裝第三方套件。

## 啟動

在本資料夾執行：

```powershell
npm start
```

然後開啟 <http://127.0.0.1:4173>。

模擬 GitHub Pages 的儲存庫子路徑：

```powershell
npm run start:pages
```

開啟 <http://127.0.0.1:4173/starcare-hollow/>。

## 操作

- 小鎮：採收藥園、交付居民委託、進入小遊戲屋並用資源升級建築。
- 收藏：行動會解鎖八種不會被消耗的手札紀念物；舊版進度會自動保留與補發。
- 星願：完成三項今日目標後領取修復禮，再由玩家決定何時進入下一日。
- 驚喜輪替：一場依序玩「翻牌記憶、雙雙消除、三件收納」；也可在開始前鎖定單一玩法。
- 翻牌記憶：先短暫預覽，再翻出兩張相同的可愛夥伴。
- 雙雙消除：圖案全部可見，快速點出相同的一對。
- 三件收納：把相同三件送入七格托盤；托盤滿而未消除會重置並計一次失誤。
- 搭檔技能：每四組成功配對充滿能量，可自行選擇「月芽提示」、「星引共鳴」或「安心時刻」。
- 成功配對：星光演出會在原牌上完成，但不會阻塞下一次點選；配錯才會短暫展示後蓋牌。
- 星脈遠征：專注不足時，在遠征面板用 1 片月芽葉調製月芽暖茶，回復最多 6 點專注；月芽葉由小鎮藥園每日採收。
- 鍵盤：Tab 移動焦點、Enter／空白鍵操作按鈕、Escape 暫停或關閉說明。
- 手機：所有核心操作都是點按，頁面可正常上下滑動。

小鎮進度會自動保存在目前瀏覽器的 `localStorage`。重新整理或下次開啟同一網址時會繼續使用原進度。

## 驗證

```powershell
npm run check
```

網址參數可縮短測試，例如 `?view=clinic&duration=30&goal=2&seed=test&debug=1`。正式預設為 120 秒、三個短關卡。

公開版由 `main` 分支自動發布至 <https://orsinobbb.github.io/starcare-hollow/>。版本升級、存檔相容與回復方式見 [GitHub 發布與長期升級規格](../docs/09_GITHUB_RELEASE_UPGRADE.md)。
