# 《星癒小鎮》完整遊戲設計總覽

> 英文工作名：Starcare Hollow
>
> 文件版本：0.5
>
> 設計狀態：小鎮核心與三種配對小遊戲原型驗證中

## 1. 一句話提案

在一座被失落星光籠罩的小鎮裡，玩家用翻牌、配對、收納等短小但有技巧的委託喚醒可愛搭檔，並把每次成果投入栽培、建造、收藏、關係與故事，逐步修復整座小鎮及居民的記憶。

## 2. 產品定位

《星癒小鎮》是一款舒適外觀、中度策略深度、可短玩也可長玩的單機經營 RPG。它服務喜歡《模擬市民 3》的空間與人物掌控、《Hay Day》的生產累積、《Hospital Mania》的時間管理，以及《Tsum Tsum》中可愛角色、角色技能與收集成長的玩家。訪談確認玩家不喜歡串連珠子本身，因此那不再是核心玩法。

遊戲不是彼此斷裂的小遊戲合輯。所有系統都回到同一件事：**讓小鎮因玩家每一次觀察、選擇與收集而永久變好。**

## 3. 設計支柱

### 3.1 每次操作都有手感

翻牌、配對、收納和施放技能都必須有立即而清晰的聲畫回饋。高手能藉記憶、觀察、預判與技能時機獲得更好結果，而非只靠數值碾壓。

### 3.2 每次遊玩都有永久累積

即使關卡未達三星，玩家仍帶回合理比例的金幣、經驗與研究資料。所有資源都有穩定用途，重複收藏品可以轉換，時間不會被完全浪費。

### 3.3 收藏會改變世界

收集不是填滿清單。角色圖鑑改變居民互動，家具套裝改變房間功能，配方開啟新策略，地區收藏則讓鎮景實際復甦。

### 3.4 關卡與技能存在多種解法

最佳選擇會隨關卡規則、盤面與玩家習慣改變。提示、自動配對與加時技能各有時機，不應存在永久通用的唯一解。

### 3.5 舒適，但不遲鈍

世界氣氛溫暖、失敗不羞辱玩家；核心關卡仍提供記憶、快速判斷、風險管理和追求高手表現的空間。

### 3.6 我的選擇與發現會被記住

故事分岔、解謎發現、遠征收藏與穿搭都寫回同一座小鎮。玩家可自由回溯選擇、跳過已讀內容，且永遠知道哪些路線已經體驗，不以重複勞動冒充內容量。

## 4. 反支柱

本作明確不採用：

- 強迫等待的體力系統。
- 限時錯過便永遠消失的收藏。
- 付費抽角色、隱藏掉落率或付費跳過難度。
- 只增加數字而不改變玩法的升級。
- 為了延長時數而重複完全相同的訂單。
- 像素級找不同、隱藏必要線索或只能亂試的謎題。
- 故意讓完美操作仍無法過關，再推銷票券、能量或解答。
- 以閃爍、震動與粒子數量取代真正的操作手感。
- 對現實疾病或醫療工作做戲謔、污名化的描寫。

## 5. 玩家幻想

玩家依序獲得五層幻想：

1. **我看懂了。** 在最後數秒完成一組關鍵配對。
2. **這是我的小鎮。** 建築、路線和裝飾都是自己的安排。
3. **我認得這些夥伴。** 圖案不只是棋子，而是有技能與故事的角色。
4. **我會漂亮地運用技能。** 提示、自動配對與加時都有自己的時機。
5. **這座鎮因我而復甦。** 長期建設在地圖、音樂與居民行為上可見。

    解鎖新圖案、玩法、地區、家具與故事
            └──────────────────────────────↺

## 7. 目標階梯

| 尺度 | 目標例 | 典型回饋 |
|---|---|---|
| 3～15 秒 | 完成一組、維持連續、施放搭檔技能 | 角色反應、音畫回饋、分數、短暫優勢 |
| 1～2 分鐘 | 完成三個短關卡、達成星級條件 | 星幣、星砂、修復度、收藏進度 |
| 10～30 分鐘 | 完成每日星願與一輪生產、調整空間 | 建築升級、家具、角色經驗 |
| 2～7 天 | 完成居民故事、精通一種玩法、開啟新設施 | 新機制、角色事件、鎮景變化 |
| 2～6 週 | 修復一個地區、完成收藏套組、培養專精隊伍 | 地圖區域、章節高潮、永久被動 |
| 數月 | 完成六區主線、全病例與高難挑戰 | 完整世界、造型與高手徽章 |

## 10. 目前鎖定與待驗證事項

### 已鎖定

- 翻牌、雙雙消與三件收納共用圖鑑、技能、獎勵與小鎮進度。
- 經營層直接影響關卡策略，而非只提供百分比加成。
- 小遊戲、解謎、遠征、故事與換裝共享存檔、收藏及世界回饋。
- 分岔可回溯、已走路線可辨識、已讀內容可跳過。
- 無付費抽卡、無體力牆、無永久錯過內容。
- 所有主要玩法能用滑鼠與觸控完成。

### 需用原型驗證

- 三種模式的輪替順序與每輪牌量是否能維持新鮮而不疲勞。
- 四組充能速度、三種技能的選擇張力與角色演出是否足夠令人期待。
- 120 秒三關是否足以形成完整節奏。
- 玩家更偏好自由擺設的效率解題，或純審美佈置。
- 平板上最小可讀尺寸與手指遮擋問題。
