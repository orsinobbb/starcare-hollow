# 《星癒小鎮》完整遊戲設計總覽

> 英文工作名：Starcare Hollow  
> 文件版本：0.1  
> 設計狀態：可進入紙上原型與美術概念驗證  

## 1. 一句話提案

在一座因「星潮」而出現奇幻病症的小鎮裡，玩家經營並自由改造療癒所；白天以即時動線管理和連鎖任務盤治療居民，空檔栽培藥草、製作用品、培養員工並探索故事，最終修復整座小鎮與居民失落的記憶。

## 2. 產品定位

《星癒小鎮》是一款舒適外觀、中度策略深度、可短玩也可長玩的單機經營 RPG。它服務喜歡《模擬市民 3》的空間與人物掌控、《Hay Day》的生產累積、《Hospital Mania》的時間管理，以及《Tsum Tsum》《Twenty》的專注操作玩家。

遊戲不是四種玩法的拼盤。所有系統都回到同一件事：**讓療癒所和小鎮因玩家每一次精準決策而永久變好。**

## 3. 設計支柱

### 3.1 每次操作都有手感

連線、指派、救急和完成治療都必須有立即而清晰的聲畫回饋。高手能藉觀察、預判與節奏獲得更好結果，而非只靠數值碾壓。

### 3.2 每次遊玩都有永久累積

即使關卡未達三星，玩家仍帶回合理比例的金幣、經驗與研究資料。所有資源都有穩定用途，重複收藏品可以轉換，時間不會被完全浪費。

### 3.3 收藏會改變世界

收集不是填滿清單。病患故事改變居民行程，家具套裝改變房間功能，配方開啟新策略，地區收藏則讓鎮景實際復甦。

### 3.4 空間與隊伍存在多種解法

最佳配置會隨病患、關卡規則與玩家習慣改變。遊戲不應存在一個永久通用的房間排列或員工隊伍。

### 3.5 舒適，但不遲鈍

世界氣氛溫暖、失敗不羞辱玩家；核心關卡仍提供緊張的排程、快速判斷和追求高手表現的空間。

### 3.6 我的選擇與發現會被記住

故事分岔、解謎發現、遠征收藏與穿搭都寫回同一座小鎮。玩家可自由回溯選擇、跳過已讀內容，且永遠知道哪些路線已經體驗，不以重複勞動冒充內容量。

## 4. 反支柱

本作明確不採用：

- 強迫等待的體力系統。
- 限時錯過便永遠消失的收藏。
- 付費抽角色、隱藏掉落率或付費跳過難度。
- 只增加數字而不改變玩法的升級。
- 為了延長時數而重複完全相同的訂單。
- 像素級找不同、隱藏必要線索或只能亂試的謎題。
- 故意讓完美操作仍無法過關，再推銷票券、能量或解答。
- 以閃爍、震動與粒子數量取代真正的操作手感。
- 對現實疾病或醫療工作做戲謔、污名化的描寫。

## 5. 玩家幻想

玩家依序獲得五層幻想：

1. **我救到了他。** 在最後數秒完成關鍵任務。
2. **這是我的療癒所。** 房間、路線和裝飾都是自己的安排。
3. **我了解這些居民。** 病患不再只是訂單，而是持續生活的角色。
4. **我培養了一支好隊伍。** 成員能力互補，關係與故事逐漸成長。
5. **這座鎮因我而復甦。** 長期建設在地圖、音樂與居民行為上可見。

## 6. 核心遊戲循環

    選擇班次／隊伍／補給
            ↓
    配置房間與排定員工
            ↓
    即時接待病患 → 任務進入連鎖盤 → 連鎖處理與危機決策
            ↓
    班次結算：評價、病例、材料、故事進度
            ↓
    製作／栽培／升級／佈置／培養關係
            ↓
    解鎖新病症、地區、設備與規則
            └──────────────────────────────↺

## 7. 目標階梯

| 尺度 | 目標例 | 典型回饋 |
|---|---|---|
| 3～15 秒 | 完成 7 連鎖、消除一個急症、觸發員工協作 | 音畫爆發、分數、短暫優勢 |
| 2～5 分鐘 | 完成一個班次、保住滿意度、達成關卡條件 | 星級、病例進度、材料 |
| 15～30 分鐘 | 完成三個班次與一輪生產、調整房間 | 設備升級、家具、角色經驗 |
| 2～7 天 | 完成居民故事、研究一類奇症、建立新科別 | 新機制、角色事件、鎮景變化 |
| 2～6 週 | 修復一個地區、完成收藏套組、培養專精隊伍 | 地圖區域、章節高潮、永久被動 |
| 數月 | 完成六區主線、全病例與高難挑戰 | 完整世界、造型與高手徽章 |

## 10. 目前鎖定與待驗證事項

### 已鎖定

- 「療癒所即時動線」和「連鎖任務盤」必須是同一套因果系統。
- 經營層直接影響關卡策略，而非只提供百分比加成。
- 診療、解謎、遠征、故事與換裝共享存檔、收藏及世界回饋。
- 分岔可回溯、已走路線可辨識、已讀內容可跳過。
- 無付費抽卡、無體力牆、無永久錯過內容。
- 所有主要玩法能用滑鼠與觸控完成。

### 需用原型驗證

- 同時觀看診所與連鎖盤是否造成過量認知負荷。
- 最舒服的盤面大小、任務種類數和連鎖判定距離。
- 2～5 分鐘班次是否足以形成完整節奏。
- 玩家更偏好自由擺設的效率解題，或純審美佈置。
- 平板上最小可讀尺寸與手指遮擋問題。
