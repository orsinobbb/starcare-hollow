# UX、介面、操控與無障礙規格

> 版本：v0.6.2。核心操作是「單點卡片、辨識組合、主動選技能」與「逐格星脈遠征」；只有遠征 Canvas 會在其自身範圍內處理拖曳鏡頭。

## 0. 不可違反的體驗原則

1. **世界比例必須穩定。** 遊戲鎖定雙指縮放，避免 HUD、牌盤、地圖命中與鏡頭在操作中改變比例；真實視窗變化只會觸發響應式重排，不會改變牌局、時間或獎勵。
2. **結果必須先被看見，成功不能阻塞。** 卡片成功後立即寫入完成狀態，保留答案、光效、成功標記、文字與聲音；成功演出以獨立計時器並行播放，玩家可立刻選下一組。只有失敗比對才短暫鎖定並展示答案。
3. **特效不能取代資訊。** 關閉音效或降低動態後，成功、失誤、技能與結算仍須能靠靜態標記與文字完整理解。
4. **手勢的範圍不能外溢。** 遠征地圖可以吃掉地圖內的單指拖曳以移動鏡頭，但不可在 `body`、`document` 或其他小遊戲區攔截捲動；固定比例由 viewport 設定統一處理，不以全域事件攔截實作。
5. **每個有效動作都要有完整因果。** 玩家點下調查後，必須依序看見定位、作用（落鏟）、環境反應（碎屑／震動）、結果揭露與成果收納；不能以數字先跳動或只播一個泛用特效取代該動作。

## 1. 資訊架構

正式版主導覽預留五個目的地：小鎮、小遊戲屋、收藏冊、星願手札、設定。v0.5 原型先完成小鎮與小遊戲屋，收藏與星願顯示在小鎮頁內。

任何核心功能從小鎮最多三次操作抵達。返回先關閉最上層面板，再回小鎮；不得因返回、重試或重新整理而重複領取結算獎勵。

v0.6 新增「星脈遠征」入口：小鎮 → 星砂群島。v0.6.1 將一次調查明確切成「鏟尖定位 → 落鏟 → 地層揭露 → 遺物／羅盤回應 → 收下成果」；已翻地形、羅盤文字、粒子與寶物圖示會先呈現，再更新資源與收藏；不能只讓 HUD 數字跳動。v0.6.2 補上可見的閉環：小鎮月芽藥園採收月芽葉 → 遠征面板調製月芽暖茶 → 回復羅盤專注 → 繼續挖掘並把遺物／資源寫回小鎮。降低動態時仍保留五段文字與靜態結果，但取消震動、粒子與介面閃動。

## 2. 核心流程

```text
小鎮 → 小遊戲屋 → 選玩法與難度 → 三個短關卡
     → 星級／獎勵／收藏 → 返回小鎮 → 升級／採收／委託
```

簡報只要求兩個選擇：玩法與難度。預設「驚喜輪替＋標準」，不用先讀長篇規則便可開始。

## 3. 遊戲畫面

```text
┌───────────────────────────────────────────────────────────┐
│ 完成關數  本輪玩法  剩餘時間  失誤      暫停 說明 聲音   │
├──────────────┬────────────────────────┬───────────────────┤
│ 三關路線     │ 規則標題／進度          │ 搭檔與技能槽      │
│ 已完成標記   │ 牌盤／翻牌／收納托盤    │ 三種主動技能      │
│ 本輪提示     │ 即時成功與失誤回饋      │ 連續／組數／分數  │
└──────────────┴────────────────────────┴───────────────────┘
```

窄螢幕依序堆疊：路線 → 規則 → 牌盤 → 托盤 → 技能 → 統計。所有內容使用文件自然垂直捲動；固定 HUD 不得遮住牌盤。

### 視覺優先順序

1. 可操作卡片與目前已選卡片。
2. 當輪規則、配對成功／失誤原因。
3. 托盤容量或翻牌預覽倒數。
4. 已充滿、可主動施放的技能。
5. 時間、完成關數、連續與分數。
6. 小鎮背景與裝飾動態。

## 4. 卡片與狀態

- 最小命中區 44×44 CSS px；標準手機版以 56 px 以上為目標。
- 可愛圖案同時使用輪廓、符號、名稱與色彩，不能只靠顏色。
- 未翻、已翻、選中、提示、已完成、在托盤六種狀態必須視覺可辨。
- 已消除卡片先更新資料再重繪，並保留短暫消散演出；成功卡只在自身演出期間不可點，其他未完成卡必須持續可點。
- 翻牌錯誤必須展示兩張答案後再蓋回，避免玩家誤判輸入未生效。
- 三件收納的托盤固定顯示七格，卡片會按同類相鄰排序。

## 5. 搭檔技能

- 技能槽同時顯示數字百分比與進度條。
- 未滿時按鈕說明功能與目前充能；滿能量時有非閃爍的外框和「施放」文字。
- 玩家按下後才消耗能量，不自動代替玩家決策。
- 月芽提示用外框標出答案；星引共鳴有明確完成組合演出；安心時刻顯示加時與護盾狀態。
- 所有必要效果都有文字直播區，關閉聲音也不影響理解。

## 6. 輸入配置

| 動作 | 滑鼠／觸控 | 鍵盤 |
|---|---|---|
| 選卡 | 單點 | Tab 後 Enter／Space |
| 施放技能 | 單點技能卡 | Tab 後 Enter／Space |
| 暫停／返回 | 頂部按鈕 | Escape |
| 說明／聲音 | 頂部按鈕 | Tab 後 Enter／Space |
| 捲動畫面 | 滾輪／單指滑動 | Page Up／Down、方向鍵 |

核心盤面不監聽 `pointermove`、`touchmove` 或全頁手勢鎖。只有未來的家具佈置模式可以在明確進入後使用拖曳。

## 7. 難度與認知負擔

- 舒適、標準、專注改變牌量、翻牌預覽與失誤扣秒，不縮小卡片命中區。
- 第一關新規則只顯示一句動詞導向說明。
- 同一操作連續失敗兩次時可讓提示技能更醒目，但不自動消耗。
- 暫停、說明、頁面切到背景時停止倒數。
- 結算說明一個最有幫助的下一步，不用責備語氣或紅色失敗牆。

## 8. 視覺與動態

- 固定世界比例下，桌面與 390×844 手機不得產生文件層級水平溢位；所有核心按鈕仍至少 44×44 CSS px。
- 視窗尺寸或旋轉改變只能觸發響應式重排，不得重置牌局、改變牌量、倒數、選牌、連續數、獎勵或難度；變更前後必須能接續同一局。
- 不以手勢攔截換取穩定；盤面依實際容器寬度調整，雙指縮放則由遊戲 viewport 固定，讓按鈕與地圖命中維持一致。
- 支援 `prefers-reduced-motion`；降低翻轉、縮放與粒子，但不移除狀態變化。
- 高對比閃爍不超過每秒三次，禁止全畫面閃白。
- 背景細節不能與牌面爭奪對比；盤面使用深色底與清晰格線。
- 色覺輔助依賴圖形和名稱，不要求玩家辨別相近綠色或紫色。

## 9. 聽覺

- 正確配對音高可隨連續數漸升，但需設上限。
- 錯誤、技能、關卡完成使用不同音色；所有聲音皆有視覺對應。
- 一鍵關閉音效，按鈕狀態以文字與 `aria-pressed` 表達。
- 未來加入配音時必須有字幕、可調音量與可跳過演出。

## 10. 結算與復原

- 結算先顯示星級，再列完成關數、最佳連續、配成組數、技能次數與分數。
- 小鎮獎勵獨立成句，返回後數值立即一致。
- 提供「同盤重試」、「換新盤面」與「返回小鎮」。
- 自動存檔先備份上一份資料；版本不相容時遷移，不能靜默清空。
- 任何已入帳場次以唯一 id 去重，重複開啟結算不會再領一次。

## 11. UX 驗收清單

- 初次玩家 60 秒內能完成第一組配對。
- 玩家能說出三種玩法差異，知道可鎖定只玩喜歡的模式。
- 完成四組後能注意到技能可用，並理解三招差異。
- 翻牌、配錯、消除、入托盤與托盤重置都不出現畫面／資料不同步。
- 手機垂直滑頁正常；點卡不拖動畫面，也不造成橫向位移。
- 灰階、低動態、關閉聲音與鍵盤操作都能完成一場；手機以固定世界比例保留一致的觸控命中。
- 成功配對必須依序呈現「保留兩張答案 → 明確成功標記／光效與文字 → 淡出」；禁止無提示地直接消失。低動態模式仍保留成功標記與文字。
- 結算後，小鎮、每日星願與收藏冊進度一致。
