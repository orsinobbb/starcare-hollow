# UX、介面、操控與無障礙規格

## 1. 資訊架構

主選單後進入小鎮，不先丟出功能清單。所有主要功能都有世界中的入口，同時保留快速導覽列。

    標題
      ├─ 繼續
      ├─ 存檔
      ├─ 設定
      └─ 無障礙快速設定

    小鎮主畫面
      ├─ 療癒所
      │   ├─ 班次選擇
      │   ├─ 建造／佈置
      │   ├─ 員工
      │   └─ 病例簿
      ├─ 藥園
      ├─ 工坊
      ├─ 地區地圖
      ├─ 居民／委託
      └─ 收藏／相簿

全域快速列只保留：地圖、療癒所、人物、病例、背包、設定。出現紅點的功能同時不得超過兩個。

## 2. 核心畫面流程

### 2.1 開始一個班次

    地圖節點
      → 關卡卡片（目標／新機制／獎勵）
      → 隊伍與設備檢查
      → 班前道具
      → 開始班次
      → 結算
      → 立即重試／下一節點／回療癒所

從看見關卡到進入遊戲最多三次確認。若沿用上次配置，玩家可一鍵開始。

### 2.2 建造

    進入建造模式
      → 選房間或物件類別
      → 預覽佔地、操作面與動線熱圖
      → 放置／旋轉
      → 即時可達性檢查
      → 儲存為配置預設

離開時只有未放置物件才需確認；已合法放置的改動自動儲存。建造前自動建立復原點。

### 視覺優先順序

1. 目前手指／滑鼠連線與將完成的工作。
2. 即將逾時的任務和對應病患。
3. 關卡主要目標。
4. 可用技能與特殊珠。
5. 分數、次要挑戰和掉落。

低優先資訊不得以持續彈跳或閃爍爭奪視線。

## 4. 核心互動規格

### 4.1 任務珠

- 基準直徑：1080p 下 58～64 px；觸控實際命中區至少 72 px。
- 滑鼠按下或手指觸碰後 50 ms 內顯示選取狀態。
- 路徑跨入下一珠中心 60％半徑即算連入。
- 可沿原路退回上一珠以取消最後一步。
- 合法連線使用實線和遞增音高；非法目標以短促柔和阻力回饋，不震動整個畫面。
- 釋放後 80 ms 內先顯示成功，再開始消除動畫。
- 完整消除與補珠控制在 320～450 ms，允許動畫中預輸入下一次操作。

### 4.2 病患與設備

- 點病患：展開一行狀態卡；再次點擊或點空白關閉。
- 長按病患：進入手動指派，合法設備發光。
- 拖曳病患：路徑以虛線預覽，放到非法位置會回彈且不扣任何資源。
- 點設備：顯示佇列、所需工作與員工。
- 所有長按功能都有等效按鈕，不強迫精細手勢。

### 4.3 危機模式

任務首次進入危急時：

- 只在每班第一次觸發 0.65 秒慢動作。
- 畫面以方向性光線連接任務珠和病患。
- 不使用全螢幕紅色閃爍。
- 後續危急僅以聲音、邊框與可選震動提示。

## 5. 輸入配置

| 功能 | 滑鼠／鍵盤 | 觸控 |
|---|---|---|
| 連鎖 | 左鍵按住拖曳 | 單指拖曳 |
| 查看病患 | 左鍵 | 點按 |
| 手動指派 | 左鍵長按或 R | 長按 |
| 啟動技能 | 數字 1～3 | 點技能肖像 |
| 使用道具 | Q／W／E | 點道具 |
| 暫停 | Esc／空白 | 右上暫停 |
| 速度 | Tab | 點速度 |
| 鏡頭 | 滾輪／中鍵拖曳 | 雙指縮放／拖曳 |
| 撤銷建造 | Ctrl+Z | 固定撤銷鈕 |

所有鍵盤指令可重新綁定。不得把必要操作綁在快速雙擊。

## 6. 畫面清晰度

### 6.1 任務色彩

| 任務 | 主色 | 輔助辨識 |
|---|---|---|
| 觀察 | #5267C9 | 眼形、向內旋轉微粒 |
| 調製 | #3FA66C | 葉形、上升氣泡 |
| 療護 | #E45D68 | 四瓣十字、向外脈衝 |
| 安撫 | #E5AD38 | 心形、緩慢呼吸 |
| 淨化 | #8B5FC0 | 六角星、碎光 |
| 協調 | #42A9B5 | 雙環、交替旋轉 |

背景盤面使用低飽和深藍灰。任何任務色與背景的關鍵圖示對比需達 WCAG 4.5:1；大型圖示至少 3:1。

### 6.2 字體

- 繁體中文正文採清楚的無襯線字；角色手寫字只用於裝飾標題。
- 1080p 最小正文 24 px，關鍵倒數 30 px，按鈕 26 px。
- 行高至少字級 1.4 倍。
- 文字不可直接壓在複雜場景上，必須有實色或霧面底。
- UI 需承受德文或俄文約 1.4 倍字串長度。

### 6.3 舒適觀察與找不同

- 每局最多 5 個有故事意義的差異，不使用像素級變色或藏在畫面邊緣的點。
- 差異可點區至少 44×44 CSS px，畫面可縮放至 200％並支援拖曳。
- 不設倒數；25 秒無進展後可選擇顯示寬泛區域，不直接圈出答案。
- 提供高對比描邊、降低背景細節、靜止粒子與前後圖疊圖滑桿。
- 連續觀察內容不超過 5 分鐘，完成後提供不帶獎勵壓力的休息提示。

## 7. 教學設計

### 7.1 原則

- 一次只教一個動詞。
- 先讓玩家看見問題，再教解法。
- 教學首次需要操作時暫停計時。
- 每段強制教學不超過 25 秒。
- 第一次做對後立刻退出引導，不要求重複三次。
- 所有教學可在病例簿的「操作手冊」重播。

### 7.2 前 20 分鐘

| 時間 | 玩家學到 | 不出現 |
|---:|---|---|
| 0～3 分 | 移動視角、與角色對話 | 貨幣、製作 |
| 3～7 分 | 三連療護、完成第一名病患 | 星級、異常珠 |
| 7～11 分 | 觀察與兩步療程 | 員工專精 |
| 11～15 分 | 簡單設備移動與動線 | 完整家具目錄 |
| 15～20 分 | 安撫、班次結算、第一項永久修復 | 委託刷新、研究樹 |

第一次遊戲結束前，玩家必須完成一個操作爽點、一個自由選擇和一個可見的永久改變。

## 8. 結算畫面

結算依序呈現，總長可快速跳過：

1. 治療完成與星級，0.8 秒。
2. 一個最值得稱讚的具體表現，如「連續挽救 3 個危急任務」。
3. 一個可改善提示，只在低於三星時顯示。
4. 收穫整合進庫存，不逐項開箱。
5. 故事或病例有進度時顯示一張卡。
6. 三個大選項：再試一次、下一班、回療癒所。

不得用十數個進度條逐一延長結算。

## 9. 無障礙選項

### 9.1 視覺

- 三套色覺辨識預設，加上始終顯示任務形狀。
- UI 縮放 80～150％。
- 文字縮放獨立於 UI 100～160％。
- 關閉螢幕震動、動態模糊、景深、色差與粒子閃光。
- 特效強度低／中／高。
- 高對比任務盤和純色背景模式。
- 重要動畫不超過每秒三次高對比閃爍。
- 找不同與線索畫面可隱藏純裝飾層，且提示不以紅綠色作唯一辨識。

### 9.2 動作與認知

- 0.75／1.0 倍遊戲速度；故事模式可讓耐心消耗降至 70％。
- 連線吸附強度三段。
- 按住切換為點選多顆，再按完成的替代操作。
- 自動暫停：視窗失焦、控制器斷線、首次危急。
- 可關閉倒數數字，只保留狀態層級；或反向只顯示數字。
- 關卡開始前清楚列出新機制和預估壓力。
- 舒適班次無失敗，仍給一般資源的 80％。

### 9.3 聽覺

- 音樂、環境、UI、語音分軌音量。
- 所有關鍵聲音均有視覺對應。
- 字幕顯示說話者、方向與重要音效。
- 連鎖音階可替換為節奏敲擊，照顧音高辨識困難。

### 9.4 難度輔助

難度選項不影響故事內容、收藏完成率或成就以外的獎勵：

| 預設 | 耐心消耗 | 異常速度 | 提示 |
|---|---:|---:|---|
| 舒適 | 70％ | 75％ | 主動提示 |
| 標準 | 100％ | 100％ | 延遲提示 |
| 專注 | 115％ | 110％ | 最少提示 |
| 自訂 | 個別調整 | 個別調整 | 個別調整 |

高手徽章記錄使用的輔助條件，但不以羞辱性文字區隔玩家。

邏輯題使用分層提示且不扣除劇情或收藏獎勵；完整護眼與公平解題規格見 [好友遊戲偏好轉譯與整合系統規格](11_FRIEND_PLAYSTYLE_SYSTEM_SPEC.md)。

## 10. 通知與時間

- 沒有作業系統推播要求；若未來加入，預設關閉。
- 現實時間不顯示「再不回來就損失」。
- 生產完成只在玩家回到小鎮時以一則彙整通知呈現。
- 任務與故事卡標明「無期限」或明確的遊戲日條件。

## 11. 錯誤與復原

| 情境 | 系統行為 |
|---|---|
| 建造後設備不可達 | 阻止開始班次，直接高亮問題格 |
| 材料不足 | 顯示缺少數量與三個可取得來源 |
| 倉庫滿 | 進暫存箱，提供整理捷徑 |
| 班次中斷 | 保存至最近波次起點，重開不扣道具 |
| 存檔損毀 | 自動讀取上一輪替檔並保留損毀檔供除錯 |
| 操作裝置切換 | 立即更新提示，不重設配置 |

## 12. UX 驗收清單

- 新玩家在沒有口頭指導下可進入第一班。
- 任務珠能在灰階截圖中正確辨識。
- 150％ UI 縮放下主要班次 HUD 無重疊。
- 觸控玩家不需把手指長時間遮住危急資訊。
- 所有核心流程可不用長按、聲音或顏色完成。
- 從班次結算回到下一班不超過 20 秒。
- 任一不可逆操作都有明確確認或可復原機制。
