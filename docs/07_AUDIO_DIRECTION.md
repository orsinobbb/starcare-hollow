# 音樂、音效與聲音回饋

## 1. 聲音目標

聲音同時負責三件事：

1. 讓連鎖操作有精準節奏和完成感。
2. 在玩家視線位於盤面時，提示診所現場的狀態。
3. 隨小鎮修復逐步增加樂器與環境生活聲，讓長期累積可被聽見。

整體聲音溫暖、細緻、有木質與玻璃質感，不採用賭場式金幣爆響或持續高頻提示。

## 2. 音樂系統

### 2.1 每區動態音樂

每個地區需要一首可分層循環曲：

- 基底層：旋律與和聲，2～3 分鐘無縫循環。
- 生活層：地區特色樂器，修復第二階後加入。
- 星脈層：鐘琴、玻璃或柔和合成聲，診療順利時加入。
- 壓力層：低音脈衝與輕打擊，急迫工作增加時淡入。
- 完成層：8～12 秒章節／地標解決樂句。

| 地區 | 主要樂器 | 節奏感 |
|---|---|---|
| 暖燈街 | 木吉他、單簧管、手風琴 | 穩定步行感 |
| 月芽溫室 | 木琴、撥弦、葉片打擊 | 生長與擺動 |
| 潮聲碼頭 | 手碟、低音提琴、水滴打擊 | 潮汐起伏 |
| 風鈴高地 | 長笛、風鈴、輕鼓 | 開闊與流動 |
| 暮影舊城 | 鋼琴、中提琴、劇場小鼓 | 記憶與停頓 |
| 星墜盆地 | 玻璃琴、柔和合成器、低吟 | 神秘但不威脅 |

### 2.2 班次音樂狀態

- 暖身波：基底層。
- 工作量超過 60％：加入節奏層，不加快整首 BPM。
- 首項危急：加入低音脈衝。
- 安定度低於 30：旋律減少、保留可讀節拍。
- 成功救回危急：短樂句後恢復原層。
- 暫停：低通處理並降低 8 dB，不突然切斷。

音樂狀態轉換使用 0.5～1.5 秒交叉淡化，並盡量對齊小節。

## 3. 任務珠聲音語言

六類珠各有固定音色，不只靠音高：

| 任務 | 音色 | 質感 |
|---|---|---|
| 觀察 | 木質馬林巴 | 清楚、聚焦 |
| 調製 | 玻璃瓶與水滴 | 輕盈、上升 |
| 療護 | 柔和手鼓與木塊 | 穩定、落地 |
| 安撫 | 鐘琴與呼吸墊音 | 溫暖、延展 |
| 淨化 | 水晶擦奏 | 清除、透明 |
| 協調 | 兩個交錯音色 | 左右呼應 |

連線每增加一珠提高音階一步，但限制在舒適音域。第七顆後以和聲增加取代持續升高，避免刺耳。非法連線只發出柔和木質「扣」聲，不使用錯誤警報。

## 4. 關鍵音效

| 事件 | 聲音要求 |
|---|---|
| 選取珠 | 30～60 ms 清楚起音 |
| 形成合法三連 | 短和弦確認 |
| 產生特殊珠 | 依 5／7／10／13 連逐級增加層次 |
| 任務流向設備 | 有方向感的滑音 |
| 工作完成 | 對應設備材質聲＋角色回應 |
| 急迫 | 每個任務只提示一次，不循環尖叫 |
| 危急 | 低沉雙拍，可由設定關閉 |
| 病患安心 | 柔和吐氣、衣料或種族特有聲 |
| 紊亂生成 | 乾燥裂紋聲，與一般珠明顯不同 |
| 建造放置 | 木、石、布等材質變體 |
| 收藏完成 | 3 秒內可跳過的專屬樂句 |

同一音效至少準備 4 個細微變體，避免高頻操作造成機械重複。

## 5. 角色聲音

- 不做全語音，降低成本並保留多語彈性。
- 12 名員工每人約 20～30 個無語意情緒短聲：招呼、思考、擔心、安心、慶祝。
- 36 名主要居民每人 6～10 個短聲；一般訪客依聲線組共用。
- 短聲不得與對話文字形成語意矛盾。
- 玩家可個別關閉角色短聲。
- 生物使用真實動物聲音的重新設計混合，不直接使用令人不適的尖叫。

## 6. 環境聲

每區至少三層：

- 固定底層：風、水、室內空氣。
- 時間層：晨鳥、市集、夜蟲、遠鐘。
- 修復層：居民交談、工坊、船、風車或劇院排練。

鏡頭拉近特定設備時可聽見局部細節，拉遠時合併成柔和環境。環境聲不得遮蔽危急提示。

## 7. 混音優先順序

1. 當前連線與釋放。
2. 危急／病患離院警示。
3. 工作完成與技能。
4. 角色短聲。
5. 音樂。
6. 環境。

當三個以上完成音同時播放，使用聚合音效而非疊加全部。危急提示觸發時，音樂短暫降低約 3 dB；對話出現時降低 5～7 dB。

## 8. 無障礙

- 音樂、環境、角色、UI、任務、警示六個音量滑桿。
- 單聲道模式。
- 重要方向聲同時有視覺線索。
- 「減少高頻」選項替換玻璃與鐘琴音色。
- 「節奏提示」可顯示連鎖節拍外圈。
- 不要求玩家依聲音完成任何任務。
- 字幕可標示非語音事件，例如「右側診療床：工作急迫」。

## 9. 音訊資產估算

| 類別 | 預估 |

| UI 音效 | 約 35 |
| 任務珠與特殊珠 | 約 70 |
| 設備聲 | 18 組 × 4～6 |
| 奇症與特效 | 約 90 |
| 建造／家具 | 約 50 |
| 員工短聲 | 約 300 |

垂直切片只製作暖燈街一組動態曲、四類珠、四件設備、三名員工及六種病患的必要聲音。

## 10. 音訊驗收

- 閉眼時能藉音色分辨至少四種初期任務珠。
- 連續遊玩 20 分鐘後，連鎖音不造成高頻疲勞。
- 低音量下仍能辨認危急與完成，不必把整體音量開大。
- 同時觸發五項工作時不削波、不形成刺耳噪音牆。
- 關閉音效後，所有遊戲資訊仍完整可讀。
- 地區完成修復後，玩家能從音樂／環境察覺世界變得更有生命。
