# 經營、養成與長期進度

## 1. 日常節奏

遊戲中的「一天」是內容節點，不與現實時間強制同步。玩家可自由結束一天；離線只完成已排入的生產，不會讓角色生病、作物枯死或錯過故事。

一個典型遊戲日包含：

1. 早晨信箱：最多三則新消息，包含故事、訂單或居民邀約。
2. 栽培與工坊：收成、安排 1～3 個生產項目。
3. 選擇班次：主線、自由門診、角色支線或地區請求。
4. 班前準備：隊伍、設備、家具預設與道具。
5. 完成 1～3 個班次。
6. 診所時間：升級、佈置、角色對話、病例研究。
7. 夜間總結：顯示鎮民變化與明日預告，由玩家決定是否進入下一天。

只想玩兩分鐘時，可以直接進行自由門診；想長玩時，可以連續推進多日。

## 2. 療癒所建造

### 2.1 空間規則

- 以 1×1 格為最小單位；原型診所 12×8 格。
- 外牆、入口與固定管線不可任意移動，其餘皆可重建。
- 設備需有至少一格可站立的操作面。
- 病患與員工通道至少一格寬；死路會在建造模式中標示。
- 房間由牆、門及地板區域自動辨識，玩家也可手動命名。
- 移動、收納已購物件免費，避免實驗配置受到懲罰。
- 班次開始前自動檢查不可達設備、入口堵塞與缺少必要設備。

### 2.2 房間品質

每個房間有四個可獨立觀察的屬性：

| 屬性 | 來源 | 效果 |
|---|---|---|
| 動線 | 距離、門、障礙物 | 影響移動與排隊 |
| 機能 | 設備、照明、收納 | 影響準備速度和故障率 |
| 舒適 | 座椅、植物、空間感 | 影響病患安定度 |
| 風格 | 套組與個性搭配 | 影響特定訪客及拍照收藏 |

房間不顯示單一「總分」。單一高分會誘導玩家堆滿最有效率家具，破壞自由佈置。

### 2.3 房間套組

相容物件形成「氛圍標籤」，而非必須擺齊固定家具：

- 林間小屋：至少三件木質／植物物件。
- 星象研究：星圖、黃銅、深藍標籤合計四點。
- 暖陽茶室：暖色、布織、茶具標籤合計四點。
- 潮汐靜室：水景、圓形、冷色標籤合計五點。

達標後提供小型玩法變化，例如病患入室時恢復安定度，或特定任務更容易產生預備珠。相同標籤效果有上限，避免功能性堆疊。

## 3. 設備與科別

### 3.1 設備屬性

每件設備具有：

- 佔地與操作方向。
- 支援的任務類型。
- 同時容納人數。
- 準備時間。
- 工作需求點數。
- 舒適度修正。
- 一個可選模組槽。

### 3.2 升級不是純數值

設備最多升到三級，每次從兩個互斥改造中選一個，可支付少量費用重置。

範例：藥劑台

| 階段 | 分支 A | 分支 B |
|---|---|---|
| 1→2 | 雙研缽：可排兩份藥，但工作珠增加一點 | 精準滴管：只排一份，長連鎖時有機率不耗材料 |
| 2→3 | 流水架：相鄰調製設備共享餘韻 | 隨身箱：員工可把完成藥劑送到鄰室 |

每個設備分支都應改變空間或盤面決策，不採用只有「速度＋5％」的升級。

### 3.3 科別解鎖

| 科別 | 主要工作 | 提供的新策略 |
|---|---|---|
| 基礎照護 | 觀察、療護 | 核心教學與一般病患 |
| 星草藥劑 | 調製 | 生產配方與預製工作 |
| 心緒照護 | 安撫 | 主動管理耐心與共感病症 |
| 靈光淨化 | 淨化 | 盤面異常與污染處理 |
| 生物照護 | 協調、療護 | 大型病患、設備佔位 |
| 星潮研究 | 全類型 | 首領奇症與規則改造 |

## 4. 藥園與工坊

### 4.1 設計目的

提供《Hay Day》式的生產、訂單與看著庫存成長的滿足，但不讓等待阻止核心關卡。一般班次永遠可免費進入；製作品只提供策略、委託與收集價值。

### 4.2 生產鏈

    種子／採集物
        → 基礎藥材
        → 工坊加工品
        → 診療道具、家具材料或居民委託

範例：

    月芽種子 → 月芽葉 → 靜心茶包 → 班前道具「茶點籃」

### 4.3 時間規格

| 類別 | 製作時間 | 用途 |
|---|---:|---|
| 常用藥草 | 2～8 分鐘 | 基礎道具與訂單 |
| 加工材料 | 5～20 分鐘 | 藥劑、家具 |
| 特色配方 | 15～45 分鐘 | 支線、套裝 |
| 地標工程 | 1～3 個遊戲日 | 城鎮長期建設 |

- 工坊初始兩格佇列，最高四格。
- 可在活躍診療中獲得「靈感」，直接縮短正在製作項目，讓技巧反饋至經營層。
- 離線完成後停在成品狀態，不佔用倉庫、不腐壞。
- 所有等待可藉正常遊玩縮短，不販售即時完成券。

### 4.4 倉庫

- 基礎容量 60 格；同類材料疊至 99，不同品質不拆格。
- 任務關鍵物不佔容量。
- 容量升級使用常見建材，不依賴稀有隨機掉落。
- 滿倉時班次獎勵進入 20 格暫存箱，不會直接消失。
- 庫存介面可鎖定保留量，製作與訂單不得自動耗用鎖定材料。

## 5. 居民委託

同時最多顯示五張委託卡：

- 兩張日常委託：常見材料，報酬穩定。
- 一張故事委託：推進居民關係。
- 一張建設委託：提供地區貢獻。
- 一張高手委託：要求指定班次條件，報酬為外觀。

玩家可拒絕日常與高手委託；每個遊戲日免費刷新一次。故事委託無期限，拒絕只會放回事件池。委託會先顯示所有需求與報酬，不使用驚喜箱。

## 6. 員工養成

### 6.1 基本數值

員工只有四項可讀數值：

| 數值 | 功能 |
|---|---|
| 敏捷 | 移動、引導與設備準備 |
| 洞察 | 觀察工作、病症辨認與餘韻效率 |
| 手藝 | 調製、療護與道具效能 |
| 共感 | 安撫、安定度與關係事件 |

數值差距保持克制。滿級角色的純數值約為初始值的 1.6 倍，主要成長來自新選項和技能搭配。

### 6.2 等級與專精

- 等級 1～30。
- 完成班次獲得經驗，未上場員工獲得 30％團隊學習經驗。
- 等級 5、10、15、20 各取得一個專精點。
- 每個節點三選一，分為效率、容錯、連鎖三種方向。
- 等級 25 解鎖個人任務，完成後開啟「招牌技」。
- 等級 30 只給角色外觀與紀念家具，不製造必要戰力差距。

### 6.3 疲勞

本作不使用強制疲勞阻止玩家使用喜歡的角色。連續三班後角色只會提出休息建議；若仍出勤，會觸發生活對話但不降低能力。鼓勵輪替來自不同關卡需求與關係事件。

### 6.4 招募

所有員工透過主線、居民故事或明確任務加入。沒有隨機招募。玩家在正式加入前至少會和角色共事一次，理解其玩法。

## 7. 關係與生活模擬

### 7.1 關係值

關係分為五級：認識、熟悉、信任、知己、星盟。提升方式包括共同值班、對話選擇、完成個人事件及擺放其喜愛空間。

每一級必須解鎖一項實質內容：

- 對話與生活行程。
- 個人房間物件。
- 協作被動。
- 支線班次。
- 結局插圖或特殊造型。

### 7.2 玩家角色

玩家建立自己的「療癒所管理人」：

- 可選體型、膚色、髮型、面部特徵、服裝與稱謂。
- 外觀選項不綁性別。
- 對話選擇表達行事風格，但不設善惡值。
- 四種傾向標籤：務實、溫柔、好奇、幽默；不會鎖死劇情。
- 玩家角色平時在療癒所活動，班次中位於星脈桌操作任務盤。
- 外觀不帶戰力；可儲存 12 套命名穿搭並為日常、值班、遠征與故事場合指定預設。
- 服裝以故事、製作、收藏和明確標價取得，不使用隨機抽取。

### 7.3 日程與生活

主要居民有晨、午、晚三段簡化行程，隨地區修復而改變。玩家可在鎮上遇見角色、拍照或觸發短事件。此系統不模擬飢餓、如廁等瑣碎需求，集中在可觀察的生活感。

## 8. 病例與收藏

### 8.1 星癒病例簿

每種奇症有四層資料：

1. **初見**：輪廓、常見症狀。
2. **理解**：正確療程與盤面提示。
3. **熟練**：完成三種病患變體，解鎖研究被動。
4. **共鳴**：完成專屬故事，取得插圖與裝飾。

病例不是先收集才有必要提示。首次關卡提供足夠資訊，病例熟練只讓玩家更能預判。

### 8.2 收藏分類

| 收藏 | 取得方式 | 完成回饋 |
|---|---|---|
| 病例簿 | 治療與研究 | 病症故事、弱提示、桌面模型 |
| 居民相簿 | 關係事件 | 插圖、生活行程、結局 |
| 藥草誌 | 栽培與探索 | 新配方、花園外觀 |
| 家具冊 | 製作、商店、星級 | 佈置與氛圍標籤 |
| 星潮標本 | 首領班次 | 規則模組與展示櫃 |
| 地區印記 | 探索與建設 | 地圖外觀、音樂層次 |
| 高手徽章 | 星冠與固定種子挑戰 | 純展示、特殊連鎖軌跡 |

### 8.3 重複物處理

- 家具取得後配方永久解鎖，之後可指定製作，不靠再次隨機掉落。
- 重複標本轉為研究塵，用於指定尚缺的同系列物件。
- 系統顯示保底進度：同系列最多五次有效取得後可指定一項缺件。
- 故事收藏永不重複掉落。

## 9. 小鎮修復

### 9.1 六個地區

每區有三層修復：

1. 清理與基本通行。
2. 恢復主要設施與居民活動。
3. 完成地標，永久改變全鎮功能與景色。

地區建設使用「地區貢獻」而非一般金幣。貢獻來自治療當地居民、故事任務與建設委託，避免玩家用重複刷錢跳過內容。

### 9.2 可見變化

每次修復都至少改變兩種表現：

- 建築模型、植物與燈光。
- 環境音樂增加樂器層。
- 居民路線與群聚活動。
- 商店或生產功能。
- 新病患與野生生物。

長期進度必須在世界中可見，而不只是一條百分比。

## 10. 帳號層級與解鎖

本作不以單一玩家等級鎖所有內容，使用三條清楚進度：

- **療癒所聲望**：解鎖空間、設備與員工上限。
- **地區修復度**：解鎖地圖、故事和材料。
- **研究階級**：解鎖病症提示、配方與規則模組。

每項新功能只依賴其中一條主進度，介面可直接告訴玩家如何前進。

## 11. 結束主線後

- 可重玩所有故事班次，跳過已看對話。
- 解鎖可自訂條件的「星潮模擬室」。
- 每週固定種子挑戰會輪替，但獎勵於四週後進入常駐商店。
- 新遊戲＋保留家具配方、病例知識和外觀，不保留設備數值。
- 角色後日談依關係和地區狀態組合出現。

## 12. 存檔與時間尊重

- 三個手動存檔槽與一個自動存檔輪替組。
- 自動存檔保留最近 12 個節點：重大選擇前、事件結束、班前、班後、建造前、日結前。
- 世界時間線可以回溯；已讀場景、已走選項、首次收藏與已領獎勵另存於只增不減的「玩家記憶冊」。
- 記憶星圖標示上次選擇、已看內容與未走分岔；已讀內容可摘要或跳至下一個未讀節點。
- 所有一次性獎勵以穩定事件 ID 去重，讀取舊檔不會重複發放。
- 不在拖曳家具或盤面操作途中寫入存檔。
- 系統時間回撥不懲罰玩家，只暫停離線計算至上次時間點。
- 所有季節內容最終進入「回憶冊」，可重新啟動。
