# 美術方向、AI 繪圖需求與完整資產清單

## 1. 使用方式

本文件分成兩段：

1. **第一批概念驗證圖 A01～A08**：現在就交給繪圖 AI。先確認世界、角色、鏡頭和資訊清晰度。
2. **完整量產資產清單**：概念方向通過後才製作，避免風格尚未穩定就大量重畫。

請先只做 A01～A08，分開輸出八張原尺寸 PNG。收到後可根據畫面統一度、可玩性與製作成本再鎖定正式美術規範。

AI 圖適合用於風格探索、靜態插圖、肖像和材質概念。角色逐幀動畫、可拼接場景、九宮格 UI、透明特效及圖示仍需經過拆件、描修與一致性檢查，不能把一張概念圖直接當成完整遊戲資產。

## 2. 視覺定位

### 2.1 一句話

**如同一本可以居住的溫暖奇幻繪本：圓潤、精緻、充滿生活細節，但所有可互動資訊都像桌上寶石般清楚。**

### 2.2 風格規格

- 2.5D 手繪質感，三分之四俯視的等角空間。
- 角色約 3.5 頭身，臉與手勢在小尺寸仍可辨識。
- 輪廓圓潤但不幼兒化；成年人保有年齡、體型和個性差異。
- 場景以低至中飽和色為主，居民需求、站點與搭檔技能使用較高飽和。
- 材質有柔和筆觸、紙張與粉彩顆粒，邊緣乾淨，不做油膩高光。
- 魔法表現像呼吸、漂浮和流動，不像爆炸式戰鬥特效。
- 現實醫療符號只作抽象參考；不出現血腥、針筒恐懼或冰冷手術室。
- 每個地區有主形狀：暖燈街為方圓、月芽溫室為葉片弧線、碼頭為水平波浪、高地為斜線與風、舊城為拱門、盆地為晶體六角。

### 2.3 不可直接仿作

提示詞不要放入現有遊戲、動畫公司、在世藝術家或受保護角色名稱。使用「可愛角色技能」「舒適農園式累積」「三分之四俯視經營」「翻牌配對小遊戲」等功能描述即可。

### 3.1 全域色盤

|---|---|---|
| 夜幕藍 | #26334A | 深色 UI、卡片盤面 |
| 暖紙白 | #F5EBD8 | 面板、文字底 |

| 苔蘚綠 | #6F9B72 | 木屋、藥園 |

| 墨灰 | #343943 | 主要文字與輪廓 |

背景同一畫面的大面積飽和色不得超過三種。卡片的形狀、符號與狀態規格以 04_UX_UI_ACCESSIBILITY.md 為準。

### 3.2 材質語言

- 木：有圓角、細小使用痕跡與溫暖紋理。
- 石：霧面、邊角被腳步磨圓，不鋒利。
- 金屬：黃銅與霧銀為主，不做鏡面鉻。
- 布：可見編織與柔軟褶皺。
- 魔法晶體：半透明內發光，外輪廓仍清晰。
- UI：像壓花紙卡、琺瑯徽章與薄木框，不模擬厚重寫實材質。

## 4. 鏡頭與比例

### 4.1 小遊戲屋鏡頭

- 2:1 等角格，三分之四俯視。
- 角色垂直方向不可被高牆遮住；牆在鏡頭側自動降低。
- 1 格地板概念基準為 256×128 px。
- 一名成人站立高度約 220～250 px。
- 卡片盤面使用近乎正視角，不能被場景透視扭曲。
- 角色與背景負責情緒，盤面負責資訊；同時出現 16 張卡仍能辨認每個圖案。

### 4.2 故事鏡頭

- 角色半身像以視線高度呈現，背景柔焦但保留地區辨識。
- 關係插圖可用較自然比例的 5～6 頭身，仍維持相同臉型與服裝。
- 不以極端廣角或過度戲劇性打光破壞舒適基調。

## 5. 通用 AI 提示詞

### 5.1 共用前綴

將以下內容放在每一張提示最前面：

> 原創舒適奇幻遊戲《星癒小鎮》的視覺開發圖，2.5D 手繪繪本質感，乾淨的三分之四俯視空間，圓潤而成熟的造型，柔和粉彩顆粒，溫暖自然光，低飽和場景搭配清楚高飽和互動焦點，細節豐富但資訊層級清晰，角色具有不同年齡、體型與膚色，專業遊戲概念設計，形狀語言一致，完全原創。

### 5.2 共用負面提示

> 不要文字、不要字母、不要數字、不要浮水印、不要品牌標誌、不要現有作品角色、不要寫實醫院、不要血腥、不要針筒特寫、不要賭場或抽卡畫面、不要塑膠 3D、不要過曝霓虹、不要過度粒子、不要超細線、不要混亂背景、不要錯誤肢體、不要多餘手指、不要相互穿模、不要把 UI 和場景透視混在一起。

若工具有 negative prompt 欄位，將負面提示放入該欄；沒有則接在主提示末尾。

### 5.3 一致性要求

- 所有圖使用同一模型、版本、風格參考和相同的共用前綴。
- 有 seed 功能時記錄每張 seed。
- 角色圖以已核准的角色正面圖作 image reference，角色參考權重高於風格參考。
- 不讓 AI 產生可讀 UI 文字；按鈕保留空白，文字由遊戲內字體另加。
- 每張原圖不得經聊天軟體壓縮。
- 若工具無法直接輸出指定尺寸，使用相同比例的最大原生尺寸，再進行不裁切的高品質放大。
- 生成前確認模型、素材和平台條款允許預定的商業用途，並保存來源與授權紀錄。

## 6. 第一批概念驗證圖

### A01：世界與核心幻想主視覺

**用途**：確認整體情緒、角色魅力與世界賣點。  
**尺寸**：3840×2160，16:9，PNG。  
**構圖**：玩家管理人站在翻修中的療癒所門口，莉歐娜、奧連和兩名不同種族居民正在協助；遠處可看見暖燈街、月芽溫室與星墜盆地輪廓。畫面中央有柔和星脈連接居民和建築。  

**追加提示：**

> 黃昏的暖燈街，翻修中的木石療癒所從昏暗逐步點亮，前景是可自訂的年輕管理人、暖橙短外套的護理師莉歐娜、深綠背心與白灰捲髮的老藥劑師奧連，旁邊有麵包師和小型雲獸，大家正在共同整理招牌與藥草。星脈像細緻的金色與青色光線穿過街道，遠景有玻璃溫室、潮聲碼頭與晶體山谷。角色表情有故事感，不擺英雄戰鬥姿勢，留出右上方乾淨空間供未來標題使用。

**驗收**：縮至 25％仍能辨認療癒所、三位主角和星脈；不是一般魔法戰鬥海報。

### A02：核心小遊戲畫面概念

**用途**：驗證可愛配對牌、三關路線與搭檔技能是否可同時閱讀。
**尺寸**：3840×2160，16:9，PNG。  
**構圖**：上方為小遊戲屋生活場景，中下方是平整牌盤，左側三關路線，右側三張技能卡；UI 只有無字圖形佔位。

**追加提示：**

> 橫向 16:9 的高完成度休閒遊戲介面概念圖，背景是黃昏金光中的木石奇幻小遊戲屋，書架、藥草、黃銅燈與三位可愛搭檔在上半部生活化互動；中下方是一塊正視角、深夜藍底、黃銅細框的清楚卡片盤，排列十二張圓角翻牌卡，卡面角色依序包含蓬鬆雲獸、月芽精靈、花朵精靈、星鳥、葉片幼獸與水晶精靈，每一種都有完全不同的輪廓、表情、符號與配色，正在配成的一對有柔和金綠光框並逐漸化成星屑。左側有三個無字關卡節點，分別以翻牌、兩張配對、三件托盤圖形表示；右側是艾芙月芽提示、賽恩星引共鳴、絨絨安心時刻三張主動技能卡與共用充能環。畫面有足夠留白供 HTML 文字覆蓋，牌盤水平垂直端正，不使用珠子、不畫拖曳路徑、不含假文字，場景細緻但盤面對比最高。

**驗收**：翻開兩張→相同配對→能量增加→技能可用的因果一眼可懂；六種卡在灰階仍因輪廓可辨；盤面沒有假文字。

### A03：暖星小遊戲屋環境與模組

**用途**：確認可建造場景風格和拼接可行性。  
**尺寸**：3072×3072，1:1，PNG。  
**構圖**：一間切開外牆的 12×8 格小遊戲屋，旁邊排列模組樣本。

**追加提示：**

> 等角視角的奇幻小遊戲屋環境設計板，主畫面是一間 12×8 格、切開前牆的木石工坊，清楚分成迎賓茶席、桌遊桌、卡片展示牆、星光調製台、收藏櫃與小庭園；走道與可互動家具的操作面明確。畫面邊緣整齊展示可拼接的木地板、石地板、內牆、外牆、門、窗、轉角、半牆與拱門模組，不含文字標籤。暖紙白牆面、琥珀燈、苔蘚綠植物、黃銅器具，沒有角色遮住模組。

**驗收**：看得出哪些部分能重複拼接；家具和牆體不互相穿透。

### A04：三位搭檔技能卡與狀態

**用途**：鎖定角色魅力、主動技能辨識與按下技能的期待感。
**尺寸**：3072×3072，1:1，透明或純深藍背景 PNG。  
**構圖**：三列技能卡，每列展示未充能、充能中、可施放、按下、效果中的五種狀態。

**追加提示：**

> 專業休閒遊戲技能卡概念板，單純深夜藍背景，三列原創可愛搭檔與其主動技能：溫柔花精靈艾芙的月芽提示，圖形為月牙環繞兩張發光卡，效果是標出一組答案並短暫透視牌面；沉靜星術師賽恩的星引共鳴，圖形為星光把相同卡片牽在一起，效果是自動完成一組；蓬鬆雲獸絨絨的安心時刻，圖形為雲朵抱住金色愛心與小時鐘，效果是增加時間並形成一次保護盾。每列依序展示灰暗未充能、部分發光充能中、金邊可施放、按下回饋、角色跳出施放中的五種狀態。角色肖像圓潤可愛、表情鮮明，技能圖形輪廓完全不同，沒有珠子、沒有文字、沒有數字、沒有品牌角色。

**驗收**：三個技能只看輪廓與角色仍可分辨；縮到 96 px 仍可辨識；可施放狀態不只靠顏色或閃光。

## 8. 完整角色資產清單

### 8.1 玩家角色

| 類別 | 數量／規格 |
|---|---|
| 基礎體型 | 4 種，不綁性別 |
| 膚色 | 12 色，材質與光照測試 |
| 臉型 | 8 |
| 眼型／眉型／鼻型／嘴型 | 各 10～16 |

服裝拆件需處理不同體型，不直接要求 AI 產出整套逐幀動畫；先做正側背設計與分層切件規劃。

### 8.2 十二名員工

每人需要：

- 正、側、背三視圖。
- 3.5 頭身遊戲比例全身圖。
- 半身肖像 1024×1024：6 個表情。
- 角色選擇卡 1024×1536。
- 工作姿勢：走、引導、操作兩類設備、交談、休息。
- 主動技能姿勢與一張關係完成插圖。

## 17. 圖像驗收量表

每張概念圖 1～5 分：

| 項目 | 問題 |
|---|---|
| 原創性 | 是否像本作，而非某個既有作品的變體？ |
| 可讀性 | 縮小後是否仍知道角色、互動物和危機？ |
| 一致性 | 比例、光源、材質和色盤是否屬於同一世界？ |
| 情緒 | 是否溫暖但保有任務張力？ |
| 可製作性 | 能否拆成模組、動畫與狀態，而不只是一張漂亮圖？ |
| 無障礙 | 是否不只靠顏色、閃光或細節傳達資訊？ |
| 敘事性 | 圖中角色是否正在生活或合作，而非只是擺姿勢？ |

任何圖在可讀性或可製作性低於 3 分，不進入正式資產階段。
